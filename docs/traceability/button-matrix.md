## 1. Universal UI State Contract (Applies to Every Screen — Blueprint Sec. 11 & 20)

| State | Mandatory UI & Client Behavior | Mandatory Backend / Data Guarantee |
|---|---|---|
| **Initial App Bootstrap** | Branded shell with official emblem/wordmark (asset pending), `24–32px` spinner, accessible `"Loading your workspace"`. At `2s` display status text; at `10s` expose **Retry** and **Help/Support** (never infinite spinner). | Health/session endpoint returns role, permissions, and feature flags without leaking secrets or PII. |
| **Route Navigation** | Keep sidebar & top bar mounted; render content skeleton matching target layout (cards/table rows). | Cancel in-flight previous route queries via `AbortController`. |
| **Dashboard / List Data** | Progressive section skeletons; **never** render `0` KPI counts before API completes. | Server aggregates return timestamp/data-provenance and role-filtered scope. |
| **Table Search / Filter** | Dim prior rows with subtle progress indicator; `300ms` debounce; sync filters to URL query params. | Parameterized server-side pagination, sorting, and filtering; discard stale responses. |
| **Form Submission** | Disable only the submitting button (`aria-busy="true"`), generate `Idempotency-Key` UUID per logical submit attempt, show explicit server receipt on success. | Transactional commit + `idempotency_keys` table prevents duplicate records on retry/double-click. |
| **Draft Autosave** | Status pill cycles `Saving…` → `Saved at HH:MM` → `Offline / Sync Pending` → `Retry`. Never emit customer notifications on draft save. | Draft endpoints (`POST/PATCH .../drafts`) store non-final state privately; local offline drafts encrypted and blocked for payment/ticket actions. |
| **File Upload** | Validate extension & byte cap client-side, show filename + `%` progress + `Cancel` / `Retry`; display separate `Scan Status` and `Review Status`. | Pre-signed upload to private bucket, MIME/magic-byte sniffing, optional malware scan hook, no public URLs. |
| **Background Jobs** | Visible pipeline state: `Queued` → `Running` → `Completed` / `Failed` / `Needs Review`; expose sanitized failure reason. | `outbox_events` & `scheduled_jobs` use unique `dedupe_key`, bounded retries, and dead-letter review. |
| **Network Loss / Offline** | Non-blocking offline banner; queue permitted non-sensitive field drafts locally; **disable** payment verification, ticket issuance, and publishing. | Server rejects stale optimistic `version` / `ETag` (`409 Conflict`) upon reconnect and surfaces conflict diff. |
| **Error State** | Concise user message, support `requestId`, **Retry**, **Back**; zero stack traces, SQL errors, tokens, or cross-user PII. | Structured JSON error envelope `{ code, message, requestId, fieldErrors }`. |
| **Empty State** | Distinguish `"No records yet"` (offer primary Create CTA if permitted) vs `"No matching filter results"` (offer **Clear Filters**). | Return empty paginated collection `200 OK` with total `0` when authorized, `403` when forbidden. |
| **Long Operation (`>10s`)** | Stage indicator + safe **Cancel** button; resume via persisted job ID without polling storm (exponential backoff / SSE). | Async job ID persisted; cancellation checks safe rollback point. |
